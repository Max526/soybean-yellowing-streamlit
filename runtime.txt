# 大豆葉片黃化程度分析 Streamlit 平台｜春秋季正式版

這是一個以 **YOLO11n 葉片偵測** 與 **HSV 色彩分析** 為核心的 Streamlit 平台，用於量化大豆葉片黃化比例。

本版已更新為春季 + 秋季正式訓練權重，定位為「黃化程度量化工具」，適合農業研究、教學展示、作物影像分析與田間初步篩檢；輸出結果可輔助觀察黃化程度，但不等同完整病害診斷。

## 春秋季正式版模型

預設模型權重：

```text
weights/best_spring_autumn.pt
```

模型與資料集資訊：

| 項目 | 內容 |
|---|---|
| 模型 | YOLO11n Detect |
| 訓練平台 | NCHC nano4 / H200 GPU |
| 資料集 | 春季 307 張 + 秋季 250 張，共 557 張 |
| Split | train 445 / val 55 / test 57 |
| Precision | 0.999 |
| Recall | 1.000 |
| mAP50 | 0.995 |
| mAP50-95 | 0.967 |

> 說明：YOLO 模型負責偵測葉片 ROI；黃化程度由 ROI 內 HSV 黃色比例、綠色比例與黃綠比進一步量化。

## 本版修正重點

- 預設權重由 `weights/best.pt` 改為 `weights/best_spring_autumn.pt`。
- 模型資訊更新為春秋季正式訓練結果。
- 保留原有 HSV 黃化比例、綠色比例、黃綠比、黃化遮罩與分級功能。
- 修正 Streamlit Cloud apt 階段的 `packages.txt` 錯誤：本專案使用 `opencv-python-headless`，不需要額外安裝 `libgl1` / `libglib2.0-0t64`，因此將 `packages.txt` 清空。
- 修正 Streamlit 新舊版本 `st.image` 參數相容性。
- 圖片讀取加入 EXIF 方向修正。
- 大圖自動縮小到指定最大邊長，降低 Streamlit Cloud 記憶體壓力並加快推論。
- 加入自動白平衡與亮度對比增強選項。
- 黃化遮罩加入形態學去雜訊，減少零星背景像素干擾。
- 模型缺失時明確提示「整張圖片 HSV 測試分析」，避免被誤認為正式 YOLO 偵測結果。

## 功能

- 支援 JPG、JPEG、PNG、BMP 影像上傳
- 可上傳單張或多張葉片圖片
- YOLO 偵測葉片位置
- HSV 分析黃色比例、綠色比例與黃綠比
- 輸出健康、輕度黃化、中度黃化、嚴重黃化分級
- 顯示原圖、偵測圖與黃化遮罩
- 支援批次分析與 CSV 匯出
- 側邊欄提供白話化參數說明
- 可調整 YOLO confidence、IoU、影像前處理與 HSV 閾值

## 線上部署建議

本專案適合部署到 Streamlit Community Cloud。

主程式：

```text
app.py
```

部署時需要的檔案：

```text
app.py
config.py
image_processing.py
model_utils.py
yellowing_analysis.py
visualization.py
requirements.txt
runtime.txt
packages.txt
.streamlit/config.toml
README.md
weights/best_spring_autumn.pt
```

`packages.txt` 目前刻意保持空白，因為 `requirements.txt` 使用的是 `opencv-python-headless`，部署時不需要額外 apt 套件。

## 安裝套件

```bash
pip install -r requirements.txt
```

## 本機啟動

```bash
streamlit run app.py
```

啟動後開啟：

```text
http://127.0.0.1:8501
```

## 診斷規則

| 黃化比例 | 分級 |
|---|---|
| < 10% | 健康 / 正常 |
| 10–25% | 輕度黃化 |
| 25–45% | 中度黃化 |
| >= 45% | 嚴重黃化 |

## 注意事項

本平台提供黃化比例量化與影像輔助判斷，不等同完整病害診斷。若要作為正式田間判斷，建議搭配：

- 土壤含水量
- 淹水處理時間
- 植株生育期
- 根系狀態
- 病蟲害紀錄
- 人工標註驗證資料
- 固定拍攝距離、光源與背景條件

## 後續可優化方向

- 加入標準色卡校正
- 加入使用者自訂黃化分級門檻
- 加入多葉片個別分析 PDF / HTML 報告
- 依實際田間資料校準黃化分級門檻
- 做跨季節 hold-out 測試，例如 train 秋季、test 春季
- 若未來有 segmentation 權重，可改用 YOLO11-Seg 遮罩取代 bounding box ROI，提高葉片區域準確度
